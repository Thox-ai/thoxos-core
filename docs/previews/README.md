# Previews — end-user experience captures

Annotated walkthroughs of the ThoxOS end-user experience, in four sets
under `walkthroughs/`:

- `a-download-and-install/` — download and install flow
- `b-first-boot-and-activation/` — first boot and entitlement activation
- `c-run-your-first-model/` — running the first model
- `d-desktop-tour/` — Desktop Edition tour

Each set carries a `WALKTHROUGH.md`, a markup walkthrough
(`walkthrough.html`) with numbered callouts, the source captures, and
baked annotated PNGs under `annotated/`. The combined walkthrough
video is `thoxos-ux-walkthrough.mp4` (49.4 s, silent).

Honesty labels: every capture is labelled REAL (an actual running
surface), SIMULATION (demo or design surface), or INSTRUCTION CARD in
[MANIFEST.md](MANIFEST.md), with SHA-256 hashes and provenance. Design
renders are labelled SIMULATION and are never presented as product
screenshots of a shipped build.
